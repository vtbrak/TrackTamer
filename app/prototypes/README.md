# Prototypes (branch `head-tail`)

Trial scripts behind the nose and rear end work (docs/ROADMAP.md §17). They
are a record of how the numbers there were made, not part of the program.
Run them from the project folder (the one holding `app` and `Examples`), for
example `app/.venv/bin/python app/prototypes/head_tail_trial.py <a scratch folder>`.
